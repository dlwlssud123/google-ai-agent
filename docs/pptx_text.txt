=== Slide 2 ===
PART 1  ·  문제 인식
현장의 현실
설비 장애 발생 시, 현장에서는 실제로 무슨 일이 일어나는가?
01
두꺼운 매뉴얼을 직접 뒤적입니다
장애 상황에서 수백 페이지 분량의 PDF·종이 매뉴얼을 직접 탐색해야 합니다. 관련 페이지를 찾는 데만 수 분이 소요되어 골든타임을 놓칩니다.
02
숙련 작업자를 찾아 구두로 전달받습니다
체계화·문서화되지 않은 현장일수록 숙련자 경험에만 의존합니다. 숙련자 부재 시 신규 인력은 속수무책이 되고, 작업자 간 기술 편차가 심화됩니다.
03
두꺼운 장갑을 낀 채 스마트기기를 조작해야 합니다
기존 디지털 솔루션은 키보드 타이핑을 전제합니다. 안전 장갑을 착용한 작업자에게는 위급 상황에서 사용하기 어렵습니다.
결과  매뉴얼 탐색 지연 → 골든타임 손실 → 설비 다운타임 → 경제적 손실의 악순환

=== Slide 3 ===
PART 1  ·  문제 인식
왜 이 시스템이 필요한가?
현장 인터뷰와 현황 분석을 통해 도출한 3가지 핵심 문제
PROBLEM 01
초기 대응지연
매뉴얼 탐색에 소요되는 시간이 설비 다운타임을 증가시킵니다. 장애 발생 후 최초 조치까지의 지연은 경제적 손실로 직결됩니다.
다운타임 = 손실
PROBLEM 02
AI 신뢰성한계
생명·안전과 직결된 보수적 현장에서 범용 LLM의 환각(Hallucination)은 치명적입니다. 원문 교차 검증 없이는 사용이 불가합니다.
Hallucination 위험
PROBLEM 03
물리적조작 한계
두꺼운 안전 장갑을 착용한 상태에서 기존 터치·키보드 인터페이스는 위급 상황에서 사용하기 매우 어렵습니다.
인터페이스 부적합

=== Slide 7 ===
PART 3  ·  핵심 기능
차별화 기능 ① — 출처 PDF 뷰어
AI 답변의 근거를 클릭 한 번으로 직접 확인 — 팩트체크 허들을 최소화
Embedded PDF Viewer
STEP 1
출처 인용 태그 자동 생성
AI 답변 하단에 근거 매뉴얼의 파일명과 정확한 페이지 번호가 태그 형태로 자동 표시됩니다.
STEP 2
클릭 → 내장 PDF 뷰어 즉시 활성화
인용 태그를 클릭하면 외부 뷰어 없이도 모달 형태로 PDF 뷰어가 슬라이드 내에서 바로 열립니다.
STEP 3
해당 페이지로 자동 스크롤
수백 페이지 문서를 직접 탐색할 필요 없이, 근거가 기술된 페이지로 즉시 이동하여 원문 교차 검증이 가능합니다.
핵심 가치  Hallucination 방지 · 작업자 신뢰도 향상 · 원문 검증 시간 단축
