# UnHarnesedYU: RAG 기반 설비 매뉴얼 지능형 질의응답 시스템 기능 명세서

본 문서는 발표 자료(Presentation) 작성을 돕기 위해 **UnHarnesedYU** RAG 시스템의 핵심 기능과 아키텍처, 기술적 차별점을 체계적으로 정리한 기능 명세서입니다.

---

## 1. 프로젝트 개요 (Overview)
* **목적**: 산업 현장의 복잡하고 방대한 설비 매뉴얼(PDF 등)에서 작업자가 필요한 문제 해결 방법과 가이드를 자연어 질의를 통해 즉각적으로 찾을 수 있도록 돕는 지능형 RAG(검색 증강 생성) 시스템입니다.
* **핵심 가치**: 정보 탐색 시간의 획기적 단축, 오조작 방지를 통한 Fail-Safe 보장, 지속적인 작업자 피드백 수집을 통한 시스템 진화.

---

## 2. 시스템 아키텍처 & 기술 스택 (Tech Stack)
* **Frontend**: Next.js (App Router, TailwindCSS 기반 프리미엄 다크 모드 UI)
* **Backend Logic**: Next.js Server Actions (클라이언트-서버 간 안전한 RPC 호출 구조)
* **Database**: Local JSON Database (`db.json` - 세션, 매뉴얼 메타데이터, 피드백 로그, QA 캐시 관리)
* **Vector Store**: ChromaDB (오프라인 오픈소스 벡터 데이터베이스, 문서 청크 임베딩 저장)
* **AI Model**: Google Gemini API (텍스트 임베딩 모델 및 GenAI 답변 생성 모델 연동)

---

## 3. 핵심 기능 목록 (Core Features)

### 3.1. 매뉴얼 적재 및 인제스천 엔진 (Manual Ingestion Engine)
* **멀티 PDF 적재**: 현장의 기기/설비 매뉴얼 PDF 파일을 드래그 앤 드롭으로 손쉽게 업로드합니다.
* **지능형 문서 분할 (Chunking)**: PDF 파서를 통해 페이지 및 의미 단락 단위로 텍스트를 추출한 뒤, 검색 정확도를 극대화할 수 있는 최적의 크기로 분할합니다.
* **임베딩 및 벡터 저장**: Google Gemini Embedding API를 활용해 고차원 벡터로 변환하고 로컬 ChromaDB의 컬렉션에 실시간 저장 및 인덱싱합니다.
* **비동기 상태 관리**: 대용량 파일 업로드 시 `pending(대기 중)` -> `success(성공)` 또는 `failed(실패)` 상태를 실시간으로 UI에 갱신하여 작업 편의성을 극대화합니다.
* **예외 격리 설계 (Robustness)**: 벡터 저장소(ChromaDB)에 일시적 장애가 발생하더라도 원본 파일과 메타데이터는 로컬 DB에 안정적으로 보존되어 부분적 서비스 가용성을 보장합니다.

### 3.2. 의미론적 검색 및 RAG Q&A 엔진 (Semantic Search & RAG Q&A)
* **자연어 질문 이해**: 작업자가 일상적인 구어체나 상황 설명("계기판에 빨간 불이 들어오고 삐 소리가 나")으로 질문해도 의도를 정확히 파악합니다.
* **컨텍스트 매칭**: 질문의 벡터와 가장 유사한 매뉴얼 단락들을 ChromaDB에서 실시간 탑-K 검색하여 최적의 관련 컨텍스트를 선별합니다.
* **안전 예외 메시지 (Fail-Safe)**: 신뢰도가 극히 낮거나 참고할 컨텍스트가 부족할 경우, 오정보(Hallucination) 제공을 원천 방지하기 위해 정형화된 안전 조치 가이드라인("관련 안전 담당자 혹은 제조사에 즉시 문의하십시오")을 출력합니다.

### 3.3. 스마트 캐싱 및 최적화 (Smart Semantic QA Caching)
* **의미론적 캐싱 (Semantic Cache)**: 동일하거나 매우 유사한 질문이 들어올 경우, 대형 언어 모델(LLM)을 다시 호출하지 않고 캐시된 답변 데이터베이스에서 즉각 응답(밀리초 단위)하여 인프라 비용을 절감하고 응답 속도를 비약적으로 향상시킵니다.
* **유사도 기반 매칭**: 단순 텍스트 일치가 아닌 코사인 유사도를 적용한 벡터 비교를 기반으로 동작하여 변형된 질문도 완벽히 커버합니다.

### 3.4. 인터랙티브 멀티 세션 UI/UX (Interactive Multi-Session)
* **대화 세션 분리**: 설비별 혹은 문제 상황별로 개별적인 채팅방(Session)을 무제한 생성하고 이력을 개별 관리할 수 있습니다.
* **세션 네이밍 및 관리**: 세션 제목을 더블 클릭하여 상황에 맞춰 수정하거나 손쉽게 개별 세션을 삭제할 수 있습니다.
* **세션별 파일 매핑 (파일 연결 관리)**: 
  * "파일 연결 관리" 모달을 통해 **각 채팅방마다 검색 범위로 삼을 매뉴얼 PDF를 개별적으로 지정**할 수 있습니다.
  * 불필요한 매뉴얼에서 오염된 정보가 검색되는 것을 방지하고, 특정 설비에 특화된 검색 컨텍스트를 제공합니다.

### 3.5. PDF 뷰어 내장 및 정확한 인용 추적 (Embedded PDF Viewer)
* **출처 및 페이지 인용 (Citations)**: 생성된 답변 밑에 근거가 된 매뉴얼의 파일명과 정확한 페이지 번호가 태그 형태로 자동 노출됩니다.
* **내장 PDF 뷰어 연동**: 인용 태그를 클릭하면 즉시 화면 내 모달 형태로 내장 PDF 뷰어가 활성화되며, **해당 근거가 기술된 페이지로 자동 스크롤/이동**합니다. 작업자는 외부 뷰어를 켤 필요 없이 즉각 팩트체크가 가능합니다.

### 3.6. 데이터 보안성 강화 (Private Data Privacy Filter)
* **민감 정보 마스킹 (PII Filter)**: 임베딩 처리 및 LLM 전송 이전에 주민등록번호, 전화번호, 이메일 주소, 사내 IP 주소, 시스템 내부 경로 등의 개인정보 및 민감 사내 자산 정보를 자동 마스킹 처리하여 외부 API 전송 시 발생할 수 있는 정보 유출 리스크를 근본적으로 차단합니다.

### 3.7. 피드백 루프 및 강화 학습 로드맵 (Feedback Loop)
* **작업자 정성 피드백 수집**: 답변 하단에 "도움이 되었나요? (예/아니오)" 피드백 단계를 제공하여 AI 제안책의 실제 현장 유효성을 기록합니다.
* **평가 로그 아카이빙**: 수집된 피드백 데이터는 내부 DB에 지속 아카이빙되며, 추후 RAG 검색 가중치를 자율 갱신하는 데이터 기반 피드백 루프의 로드맵 기반이 됩니다.

---

## 4. 발표 핵심 키워드 및 혁신성 (Highlights)
1. **Fact-Checking의 직관성**: 근거 페이지로 즉시 이동하는 내장 PDF 뷰어를 통해 현장 작업자의 팩트체크 허들을 최소화함.
2. **사내 데이터 프라이버시**: 프라이빗 필터링 레이어를 두어 기업용 보안 규정(Compliance)을 완벽하게 만족함.
3. **비용 및 속도 최적화**: 스마트 세맨틱 캐시 기술로 API 호출 비용을 대폭 절감하고 실시간 대응력을 향상시킴.
4. **선택적 컨텍스트 제공**: 세션별 파일 연결 관리로 한 화면에서 여러 이기종 설비를 혼선 없이 대응 가능함.
